# 会话行为增量

## ADD REQ-SESSION-001 — 空闲会话到期
服务端应在空闲时长达到已配置的到期阈值后拒绝受保护访问，并要求用户重新认证。到期不得删除已保存的用户业务数据。空闲时长以服务端记录的最后一次成功认证访问时间为基准。

### SCN-SESSION-001-01 — 达到阈值
- GIVEN 距最后一次成功认证访问的时间等于到期阈值
- WHEN 用户请求受保护资源
- THEN 服务端拒绝请求并返回需要重新认证的结果
- THEN 已保存的用户业务数据保持不变

### SCN-SESSION-001-02 — 尚未达到阈值
- GIVEN 距最后一次成功认证访问的时间小于到期阈值
- WHEN 用户请求受保护资源
- THEN 服务端允许访问并更新最后成功认证访问时间
