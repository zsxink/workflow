# 工作流、规格与 Agent 规范衔接复核

日期：2026-10-22。基于当前工作树的权威文档、双语安装模板、工作流/运行内核和相关测试；保留本次开始前已有修改。主会话统一修改与验证，两个只读 Agent 分别核对文档契约和实现。本文包含首轮复核及同日后续实施更新，协议以各专题文档为准，实际能力以 [实现记录](17-implementation.md) 为准。

## 判断与处理

整体职责划分合理：Spec 定义可观察行为，design/tasks 定义方案与执行边界，Developer 在任务内 TDD，Tester 核查覆盖，Reviewer 独立只读审查，Verifier 执行固定输入验证。保持既有五职责、Red/Green 分权限派发和原生宿主约束；本轮优化规范组合与交接，不据此声称完整流水线已可用。

| 问题 | 本轮处理 | 实施边界 |
| --- | --- | --- |
| 多份 Agent/项目规范缺统一组合规则 | 执行协议集中说明各来源职责、权限交集、冲突回主会话及已有授权复用；中英文模板同步 | 模型/agent_type 只选择资源，不替代权限或角色证据 |
| authoritativeDocs 未参与 policy 采样，嵌套 Agent 规范可能仅按普通 source 变化处理 | 权威文档与可枚举的各级 AGENTS.md/CLAUDE.md 保守归入 policy；忽略/产物目录中的适用规范须显式声明 | 不自动判断自然语言语义；仓库外 Skill/会话摘要绑定仍待实施 |
| source 失效矩阵不一致，正常开发/补测容易被解释为未知漂移 | 统一保守恢复起点，另定义授权 attempt 产物接收；保留历史事实，重新验收当前组合 | 新增独立产物审计/接收领域转换，保留完成历史并更新后续门禁；真实宿主应用仍阻断 |
| Tester 补测与 TDD 历史关系不清 | 新 verification 任务/attempt 记录补测；当前输入重做回归及后续 CR/Verify；缺陷回新开发 cycle | 不回填 Red，不人为让已有正确行为失败 |
| Architect 从无 tasks 草案启动存在循环 | 明确 design/tasks 可缺省为阶段产物；职责不能扩大规格写入范围 | change scope 准备已实现，taskIds=[]；真实派发关联仍待宿主验收 |
| verification/exempt 无真实开发派发路径 | 保留模式与适用性，明确当前仅有 Red/Green 开发角色 | 新增 verification/exempt 角色准备；完整结构校验及计划绑定，不借 Tester 或伪造 cycle |
| 删除行为未纳入完整追踪 | 规格规范明确删除项也需移除/替代验收及历史 ID 审计 | Requires/trace 已覆盖移除原需求/场景；用途专属证据及历史 ID 拒绝已回归 |
| 宿主优先级、doctor 就绪与实施状态描述混杂 | 统一 Codex/Claude 优先，其余后续；区分 hostExecutionReady 与生命周期就绪；旧复核标为历史 | 安装、模板和模拟协议通过均不代表真实宿主验收 |

## 成本与质量边界

小任务缩短设计与报告，复用已存在的有效测试和配置命令，按实际风险选择检查维度；不为模板凑新模块、测试或备选方案。独立审查与最终验证门禁保留。角色是否合并留待既定双仓试点，用质量、返工、时间和成本数据判断，本轮不凭推断改变已确认决策。

## 后续实施顺序

本次已补确定性准备、删除追踪与产物接收领域转换，并开放真实工作树只读审计。后续重点是原生宿主身份/授权来源、持久化接收、跨进程证据与人工替代验收来源适配，再验收最终组合、阶段成功、归档和集成；具体分层状态见 [路线图](10-roadmap.md) 文末，不将领域测试当作真实闭环。

## 同日后续实施：四条路径

Architect 无任务准备和两类非 TDD 开发准备已可从应用/CLI 使用，所有包保持 planned。非 Architect 先通过完整 spec 结构校验，避免 draft gate 漏掉任务范围、命令及依赖。exempt 强制显式 Alternative-Acceptance，仍不能据此宣称批准或已验收。

删除追踪区分 current/removal；REMOVE 读取原规格全部场景，UPDATE 读取实际移除旧场景并与删除声明核对。移除用途仅接受显式 removal 的真实自动化或手工验收引用及理由，普通 passed/not-applicable 不可替代。

产物接收领域逻辑具备完整差异审计、真实命令/计划/派发边界核验、防伪审计对象、后续失效和历史保留；仅领域转换可推进当前指纹并记录 outputReceipt，不赋予阶段成功。CLI dispatch audit 重新采样真实文件与 Git 并保持只读。当前宿主来源未验收，应用不开放接收；exempt 替代验收缺可信来源时也拒收。独立审查发现的非 TDD 结构校验缺口、同 ID 不同命令及旧命令重放问题已修复并增加回归，最终代码由主会话核对。
